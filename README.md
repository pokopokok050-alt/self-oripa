# セルフオリパ貯金 v18（仮想デモ）

1日の新規仮想入金上限を50,000円から3,000円に変更しました。日本時間の日付で集計し、上限を超える入金操作は無効になります。

抽選・クレジット・現実での使用記録など、その他の機能はv16から維持しています。同じURL・ブラウザなら保存データを引き継ぎます。

Windowsで `py -m http.server 8000` を実行し、`http://localhost:8000` にアクセスしてください。GitHub Pagesで更新する場合はZIP内の全ファイルを上書きしてください。

※本物の銀行口座とは連携しない仮想デモです。

## v18 抽選確率の変更
- 30日間、毎日3,000円のチケットを購入（合計90,000円）した場合の期待払出額が30,000円となるように調整。
- 期待還元率 1/3（33.333...%）。0倍は約84.8496%、非0倍は約15.1504%。
- 非0倍の93種類中92種類（0.5倍、1.0〜10.0倍）の相対的な重みは維持。
- くじを再購入した場合や日々の購入額が変わった場合、30,000円は保証されません。
- 過去の抽選履歴や保存データはそのままです。実際のお金は動きません。
